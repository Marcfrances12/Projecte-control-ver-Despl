Modificar estilos CSS

Ejemplo

Este texto va a cambiar de estilo.

Explicación

Cada elemento HTML tiene una propiedad style que permite cambiar su CSS desde JavaScript. Escribimos elemento.style.propiedad = "valor". Las propiedades con guion en CSS (como font-size) se escriben en camelCase (fontSize). Al pulsar el botón, el párrafo cambia de color, tamaño y fondo sin recargar la página.
